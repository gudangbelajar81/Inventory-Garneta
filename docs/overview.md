# Retail Inventory & Profit Monitoring System

Versi awal ini memakai HTML5, Tailwind CSS Play CDN, dan Vanilla JavaScript ES Modules.

## Modul

- Dashboard
- Barang
- Supplier
- Pembelian
- Repacking
- Penjualan
- Laporan
- Scanner
- Users
- Settings

## Catatan

Data demo disimpan di `localStorage`. Backend PHP/Laravel API bisa menggantikan `assets/js/api.js` tanpa mengubah struktur halaman.
